# Block Buddies — Godot Android project
This is the parallel native Godot implementation of Block Buddies.

- Engine: Godot 4.4+
- Target: Android portrait first
- Renderer: Compatibility (OpenGL ES 3)
- Entry scene: `scenes/main.tscn`

## Open
Open the `godot/` folder in Godot 4.4 or newer and run the project.

## Current vertical slice
The starter build contains a playable 10×20 falling-block loop with keyboard and large touch controls. It is a technical foundation; it does not yet claim parity with all existing modes or progression systems.

See [Game Design](docs/GAME_DESIGN.md) and [Migration Plan](docs/MIGRATION_PLAN.md).
