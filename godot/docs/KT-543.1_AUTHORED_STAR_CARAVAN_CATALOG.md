# KT-543.1 — Versioned authored planet catalog and Star Caravan chapter foundation

## Scope
Introduces the first data-backed chapter without replacing the existing formula-derived fallback for the other 330 nodes. This is a migration seam, not a claim that all 30 Star Caravan planets have bespoke board layouts or new runtime effects.

## Implementation
- Added `godot/scripts/campaign_planet_catalog.gd` with schema version 1 and 30 authored Star Caravan planet records.
- Each record has a unique local ID, mission title, player-facing briefing, mission tag, explicit event status and optional event/boss metadata.
- Added deterministic validation for chapter identity, schema version, exactly 30 sequential records, required presentation fields, event-state vocabulary, live special-piece binding and boss metadata.
- `campaign_progress.gd` now overlays authored metadata for Universe 02 (global nodes 031–060); objective targets, rewards, progression, and all other universes retain their existing validated formula fallback.
- Planet 056 and 057 are explicitly marked as live campaign Cargo Hook content, matching the existing campaign-only special-piece runtime. The three Star Caravan bosses now have authored identities and briefings, but their encounter phases remain a later KT-546 task.
- Added `campaign_planet_catalog_test.gd` and registered it in the native Godot CI workflow.

## Important honesty boundary
The chapter now has authored mission identities and briefings, but most nodes still use the existing objective families and standard board setup. The Cargo Hook showcase is the only new special-piece event in this slice. No new hazard, gravity, wind, portal or boss-phase gameplay has been enabled. Records marked `briefing_only` are not presented as implemented mechanics.

## Protected behavior
- Unmigrated nodes continue to use the existing formula definitions.
- Campaign marks, receipts, save version and sequential unlock rules are unchanged.
- Campaign-only special pieces remain isolated from Classic, Sprint/Marathon and Block Run.
- Leaving an unfinished level still restarts that attempt; completed progress and rewards persist.
- No main merge, public deployment or APK release.
