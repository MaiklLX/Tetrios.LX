# Universe model credits

The campaign atlas uses 40 GLB models from Grab3D's Cozy Space Kit and Cozy Sci-Fi Base Kit. The publisher marks each listed model **CC0 1.0 Universal** (public domain dedication), permitting commercial use and modification without required attribution. We retain the source links as a courtesy.

The website loads from original publisher endpoints; the Android APK build downloads and bundles the same GLB files locally. Each source URL and original filename is also recorded in `manifest.json`.

## Licensing note

All selected source pages explicitly identify their individual model as CC0 1.0 Universal. We do not treat a generic "free download" label as a license; the original page for each model is retained above and in the manifest.

The 360 numbered campaign planets are procedurally generated with deterministic per-node seeds. Each planet receives its own combination of surface color, continent patches, craters, atmosphere, optional ring system and moons; these node variants deliberately stay procedural instead of upgrading to one repeated GLB.
