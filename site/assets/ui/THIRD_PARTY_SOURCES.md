# Third-party asset provenance

No third-party assets have been imported into this directory yet.

When importing a pack, create a subfolder and record:
- publisher and official source URL;
- license name and source license/readme file;
- archive filename and download date;
- original filename for each selected asset;
- any crop, recolor, conversion or other modification.

Current project-authored SVGs are listed in this directory's README.md. Third-party candidate sources and selection rules are documented in ../../docs/checkpoints/KT-425_CC0_ASSET_LIBRARY_AUDIT.md.
