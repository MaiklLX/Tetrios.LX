# CHECKPOINT 336 — первая изолированная оболочка главного меню ПК

Дата: 2 ноября 2026 года  
Ветка: `rebuild/desktop-web-v1`  
Предыдущая точка: #335 (аудит).

## Реализовано
- Создан отдельный файл `site/desktop-shell.css`.
- Новый stylesheet подключён в конце `<head>`, после старых встроенных стилей и других CSS-файлов.
- Весь новый CSS находится внутри единственного `@media (min-width: 901px)`.
- Первая desktop-компоновка главного меню построена как свободная двухколоночная сетка: бренд/герой, три режима, серия посещений, задания, ресурсы, герои, профиль, магазин, статистика.
- Все три режима `campaign`, `rogue`, `daily` отображаются в одном ряду в desktop-сетке; ни один режим не подменяет другой.
- Возвращено отображение `.shopbuttons` в отдельной области меню; старые desktop-правила скрытия перекрыты новым слоем.
- Для остальных экранов пока добавлена только общая ширина desktop-контейнера; их индивидуальная компоновка — следующий этап.

## Сохранность
- Изменены только `site/desktop-shell.css`, ссылка на него в `site/index.html` и checkpoint-документ.
- Не менялись JS, игровые обработчики, canvas, localStorage, игровой баланс, 3D-модели и игровые ассеты.
- Существующие мобильные правила не редактировались. Новый CSS активируется только при ширине окна от 901 px.
- Сохранены DOM hooks трёх режимов, кнопки сброса и canvas игрового поля.

## Автоматические проверки исходников
- Найден ровно один desktop media query `@media (min-width: 901px)` в новом файле.
- Баланс фигурных скобок CSS: 58/58.
- Ссылка на новый stylesheet присутствует ровно один раз.
- В исходном HTML по-прежнему присутствуют три `data-mode` и игровой canvas.
- Браузерная визуальная проверка ещё не выполнялась; ветка не публиковалась в `main`.

## Следующий этап
1. Проверить визуально главное меню на широком ПК-экране и при ширине около 1024 px.
2. После согласования геометрии меню перейти к отдельной desktop-компоновке игровой арены.
3. Затем оформить кампанию, ежедневный вызов/календарь, героев и магазин.
