# KT-427.1 — Buddy character states

## Character identity
Buddy is the friendly blue pixel companion for BLOCK BUDDIES. Silhouette: stepped square head, white face bezel, dark face screen, cyan pixel eyes, small orange connector/feet. The silhouette and face remain consistent across expressions.

## States added
- `buddy-idle.svg`: neutral friendly idle expression.
- `buddy-happy.svg`: smile / positive response.
- `buddy-surprised.svg`: surprised reaction / near miss.
- `buddy-victory.svg`: confident victory expression.

These are reusable source assets for future Godot AnimatedSprite2D/state animation and UI reactions. They are not yet wired into gameplay events.

## Brand polish
- Replaced font-dependent wordmark text with original 5x7 pixel glyph geometry.
- Added subtle title-logo float, disabled when reduced motion is preferred.
- Added extra narrow-screen rules below 380px.
