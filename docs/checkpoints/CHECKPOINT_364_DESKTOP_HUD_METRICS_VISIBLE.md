# TETRIOS LX — контрольная точка #364

## Исправление
Исправлена причина исчезновения метрик HUD в desktop-компоновке.

- Внешняя сетка `#game` теперь использует content-sized строки `42px auto auto` вместо последней строки `minmax(0,1fr)`, которая могла схлопывать область HUD при отсутствии фиксированной высоты контейнера.
- `.gamehud` явно закреплён в третьей строке desktop-сетки.
- Сохранены четыре независимых показателя: очки, линии, уровень и монеты.
- Изменение действует только при ширине окна от 901px.
- Мобильная раскладка, игровая логика, canvas и 3D renderer не менялись.
