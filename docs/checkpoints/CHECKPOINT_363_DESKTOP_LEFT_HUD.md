## Исправление
На desktop при ширине от 901 px блок слева с очками, линиями, уровнем и монетами принудительно формируется как одна колонка из четырёх независимых строк. Для каждого прямого дочернего показателя сброшены конфликтующие grid-row/position/float/transform/размеры и отступы; подпись и значение выровнены по разным сторонам одной строки. Для низких окон предусмотрена компактная высота строк.

Мобильные правила, игровая логика, canvas и 3D-рендерер не менялись.

## Проверка
