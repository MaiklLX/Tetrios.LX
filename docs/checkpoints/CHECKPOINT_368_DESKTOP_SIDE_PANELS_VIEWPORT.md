# TETRIOS LX — Контрольная точка #368
Дата: 2026-11-03

## Исправление
Устранено переполнение вертикальной области на desktop: блок арены больше не получает искусственную минимальную высоту 82dvh, которая раздувала общую grid-строку и выталкивала динамические панели монстра и целей за нижнюю границу окна.

- Для desktop-контейнера арены снята принудительная минимальная высота; высота возвращена к естественному размеру.
- Правая колонка с карточками и целями ограничена доступной высотой окна браузера и получила собственную вертикальную прокрутку при необходимости.
- Панели целей не сжимаются по высоте.
- Изменения ограничены шириной от 901px.
- Мобильная раскладка, игровая логика, canvas и 3D renderer не менялись.

## Проверка
Изменение внесено в CSS сайта. Автоматическая проверка браузером не выполнялась; требуется ручная проверка на desktop после Ctrl+F5, в режимах Block Run и Campaign.
