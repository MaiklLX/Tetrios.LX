# TETRIOS LX — контрольная точка 366
## Возврат игровой арены в центр desktop-страницы

Дата: 2026-11-03

### Причина
Скрипт создаёт legacy-обёртку `.gameleftcol` внутри `.playlayout`, а затем переносит `.gamehud` из неё наверх, перед `.playlayout`. Обёртка остаётся первым дочерним элементом `.playlayout`. Предыдущее CSS-правило назначало центральную колонку через `:first-child`, поэтому оно попадало в пустую/legacy-обёртку, а не в контейнер игрового поля. Контейнер арены участвовал в автоматическом размещении grid и смещался влево.

### Исправление
- На desktop (min-width: 901px) скрыта legacy-обёртка `.gameleftcol`, оставшаяся после переноса HUD.
- Реальный контейнер игрового поля выбран устойчивым селектором `.playlayout > div:not(.gameleftcol)` и явно закреплён в центральной колонке.
- Правая `.sidecol` закреплена в третьей колонке.
- HUD остаётся в первой колонке.
- Стили четырёх карточек счётчиков и круговых индикаторов не менялись.
- Мобильная раскладка, canvas, игровая логика и 3D renderer не менялись.

### Проверка
Изменение подготовлено в ветке `fix/desktop-arena-center-after-hud-2026-11-03`. После публикации требуется проверить desktop в браузере с жёстким обновлением (Ctrl+F5): HUD слева, арена по центру, монстр/цели справа. Автоматическая визуальная проверка браузера не выполнялась.
