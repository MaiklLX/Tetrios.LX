# TETRIOS LX — контрольная точка #362

Дата: 2026-11-03  
База: `main` после контрольной точки #361 (`bac6aefbc1e9e57636568cb574f94308c36bd19d`)  
Ветка: `polish/desktop-hud-compact-sidepanels-2026-11-03`

## Что изменено

Только desktop CSS при ширине окна от 901 px. Игровая логика, canvas drawing buffer, 3D-рендерер и мобильные стили не менялись.

- Все четыре показателя HUD (очки, линии, уровень, монеты) остаются отдельными вертикальными строками.
- Правая колонка уплотнена: уменьшены высоты карточек, круговых индикаторов, превью следующей фигуры и внутренние отступы.
- Карточка способности выбранного героя получила компактную высоту и уменьшенную область эмблемы, чтобы не выпадать за нижнюю границу окна.
- Для очень низких окон предусмотрен дополнительный компактный режим.
- Правая колонка может прокручиваться внутри себя как страховка для особенно низких окон.
- Немного увеличено расстояние между буквами и словами для более спокойной читаемости.

## Проверка

Изменения сохранены в отдельной ветке. Реальная визуальная проверка в браузере не выполнена; после публикации нужно проверить на ПК обычное и низкое окно. Мобильная версия не затрагивалась CSS-правилами этого прохода.

## Откат

- Принятая база до этого прохода: #361, commit `bac6aefbc1e9e57636568cb574f94308c36bd19d`.
- Более ранняя страховочная компоновка: #360, файл `docs/checkpoints/CHECKPOINT_360_DESKTOP_LAYOUT_BASELINE.md`.

## Фраза продолжения

`TETRIOS LX — продолжаем с контрольной точки 362. Проверяем четыре отдельные строки HUD, компактную правую колонку и карточку выбранного героя на обычной и низкой высоте окна ПК. Если правая колонка всё ещё не помещается, корректируем размеры по фактической высоте, не меняя мобильную версию.`
