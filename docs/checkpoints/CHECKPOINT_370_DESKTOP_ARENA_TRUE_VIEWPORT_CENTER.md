# TETRIOS LX — Контрольная точка 370
Дата: 2026-11-03

## Сохранённое состояние
Все предыдущие изменения, включая HUD слева, геометрию арены, боковые панели и адаптивную микропоправку #369, сохранены в истории Git.

## Проблема
После #369 пользователь сообщил, что арена всё ещё находится слишком высоко. Анализ CSS показал, что родительский grid `#game` имеет авто-размеряемую вторую строку: `grid-template-rows:42px auto auto`. Поэтому `align-self:center` центрировал арену только внутри короткой строки, расположенной сверху, а не внутри высоты окна браузера.

## Решение
Добавлен desktop-only слой `bb-desktop-arena-true-viewport-center-v1`:
- вторая строка grid получает высоту от оставшейся части viewport: `minmax(calc(100dvh - 42px),1fr)`;
- арена остаётся во второй строке и центрируется внутри неё;
- убран локальный translateY из #369, поскольку центрирование теперь выполняется геометрией контейнера;
- HUD остаётся в третьей строке, боковая колонка центрируется во второй строке;
- мобильная версия, размеры canvas и игровая логика не меняются.

## Проверка
Требуется проверка опубликованной ПК-версии после merge и жёсткого обновления. Визуальный QA не заявляется до подтверждения пользователя.

## Контрольная фраза
TETRIOS LX — контрольная точка 370. Проверяем центрирование арены относительно всей высоты окна браузера ПК, а не авто-высоты строки grid.
