## Изменения #385
1. APK workflow скачивает все 12 GLB-моделей вселенных в `assets/universes/models/`, проверяет GLB magic bytes и переписывает локальную копию manifest на относительные локальные URL. Веб-манифест остаётся с исходными URL.
2. Космический фон кампании явно закреплён локальным URL в мобильном Android WebView.
3. В кольцах хроно-режима и повышения уровня скрыты внутренние дублирующие пиктограммы; внешние заголовки/подписи сохранены.
4. В 2D- и 3D-арене добавлена плавная 280-мс cubic-ease анимация оседания рядов после очистки; в 3D-режиме блоки физически смещаются в целевые позиции вместо мгновенной пересборки на новом уровне.
5. В CI добавлена постоянная debug-only подпись APK, чтобы будущие CI APK могли обновлять друг друга без удаления. APK #755 был подписан прежним временным ключом, поэтому переход на новую постоянную подпись потребует один последний uninstall/reinstall.
6. Добавлен скрипт `scripts/configure-stable-android-debug-signing.py` и debug-only keystore payload `android/debug-signing.keystore.b64`. Этот ключ предназначен исключительно для тестовой debug-сборки; не использовать для release signing.

## Обязательная проверка сборки и устройства
- GitHub Actions должен успешно скачать и включить все 12 GLB.
- Проверить, что APK содержит `assets/assets/deep_space_no_sun_2k.webp`, `assets/universes/manifest.json`, все 12 `.glb`, локальный Three.js и `assets/universes-3d.js`.
- На Android проверить фон кампании и каждую 3D-вселенную, включая работу без сети после первого запуска.
- Проверить исчезновение обеих пиктограмм в кольцах.
- Проверить мягкое оседание рядов при одиночной и множественной очистке.
- Установить новую сборку поверх установленной #385; дальнейшие сборки должны обновляться поверх неё без удаления.
