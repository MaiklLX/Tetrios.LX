# CHECKPOINT 339 — desktop CSS isolation v1

Дата: 2026-11-02  
Ветка: `audit/desktop-css-isolation`  
База: опубликованный main после Checkpoint #337

## Что изменено
1. Удалён legacy-блок `bb-desktop-restoration-recovered-322` из `site/index.html`. Он содержал 11+ KB настольных правил с 210 `!important`, включая конфликтующие варианты геометрии арены и принудительный `display:grid` для экранов.
2. Новые desktop-раскладки собраны в `site/desktop-shell.css`:
   - Атлас кампании: отдельная область заголовка, вводного блока, карты и действия.
   - Ежедневный вызов: цель и правило в двух колонках, действия в нижней строке.
   - Магазин: две наградные станции рядом, каталог на всю ширину.
   - Герои: сетка экипажа, затем отдельное досье выбранного героя.
   - Диалоги календаря/героя/настроек получают desktop-ограничения ширины.
3. Все правила отображения экранов защищены условием `:not([hidden])`: неактивная страница не должна появляться только из-за desktop grid.
4. Разметка зон опирается на реальные DOM hooks `#dailyGoal`, `#dailyRule`, `#shopBuyBox`, `#bbRelicChestOptions`, а не на хрупкое положение div-элементов.

## Что сохранено
- Мобильные правила и космическая карта не удалялись.
- Игровые JS-скрипты и обработчики не менялись.
- Canvas игрового поля, pause, controls и режимы campaign/rogue/daily сохранены.
- Существующий внешний visual-overhaul.css сохранён; новый desktop stylesheet подключён ровно один раз.
