# TETRIOS LX — Контрольная точка 369
Дата: 2026-11-03

## Цель
Финальная микрокоррекция вертикального положения арены в ПК-версии: пользователь сообщил, что после #368 арена остаётся немного выше визуального центра окна браузера.

## Изменение
В `site/index.html` добавлен отдельный desktop-only CSS слой `bb-desktop-arena-final-viewport-nudge-v1`.
- Сдвигает только `.boardframe` вниз на адаптивные 6–11 px (`clamp(6px,1.1dvh,11px)`).
- Не меняет grid-геометрию, высоту `.playlayout`, боковые панели, HUD или мобильные стили.
- Не затрагивает canvas, игровую логику и размеры игрового поля.

## Проверка
Изменение требует проверки на опубликованной ПК-версии после обновления страницы (Ctrl+F5). Браузерное визуальное QA этим коммитом не заявляется.

## Контрольная фраза
TETRIOS LX — контрольная точка 369. Проверяем финальное вертикальное центрирование арены в ПК-версии; сдвиг затрагивает только игровое поле.
