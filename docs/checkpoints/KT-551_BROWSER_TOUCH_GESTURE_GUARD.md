# KT-551 — Защита браузерного управления от случайного диагонального жеста

- Дата: 2026-11-09
- Ветка: `web/kt550-browser-return-2026-11-09`
- Изменения: `site/index.html`, `scripts/cross-platform-visual-preview.cjs`
- Статус: код внесён; CI и браузерные артефакты ожидаются.

## Изменения

- Порог доминирования оси жеста увеличен с 1.12 до 1.45.
- Чёткий горизонтальный жест сохраняет движение влево/вправо.
- Чёткий вертикальный жест сохраняет soft-drop и вращение свайпом вверх.
- Диагональный жест без выраженной доминирующей оси помечается ambiguous и поглощается: он не должен превращаться в случайное вращение или движение.
- DROP guard остаётся отдельным и применяется только к hard-drop; движение и вращение после DROP не блокируются.
- Cross-platform тест дополнен проверкой, что диагональ не меняет состояние фигуры.

## Не менялось

- Физика, скорость падения, scoring, режимы и схема сохранений.
- Desktop keyboard controls и действия экранных кнопок.
- 2D Canvas runtime и пропорция поля 10×23.

## Проверки и ограничения

- Автоматический сценарий Chromium/WebKit расширен; результат будет внесён после CI.
- Синтетические touch events не заменяют ручную проверку физического телефона.
- APK не собирался; Pages не публиковался; main не изменялся.
