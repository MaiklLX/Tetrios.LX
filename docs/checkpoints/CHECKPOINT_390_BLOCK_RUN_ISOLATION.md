### Реализовано
1. Добавлена явная классификация roguelike-карт, связанных с монстрами и комнатами:
   - `burst` — дополнительный урон монстру;
   - `rift` — эффект после победы над монстром;
   - `reserve` — поглощение атаки монстра;
   - `hunter` — дополнительный урон монстру.
2. Добавлен `bbGetModeUpgradePool()`: Block Run получает полный набор карт, остальные режимы получают фильтрованный стандартный пул без monster-only эффектов.
3. Окно повышения уровня использует пул в соответствии с текущим режимом. В Block Run остаются ранги карт и синергии; стандартные режимы используют обычный выбор реликвии без rogue-рангов.
4. Стартовый случайный карточный бонус Блипа теперь выдаётся только в Block Run. Описание героя уточнено.
5. Добавлен `site/validate-gameplay-modes.mjs` и подключён к cross-platform CI.

### Защищённые правила
- Монстры, комнаты, их атаки, цели Block Run, ранги и синергии остаются привязаны к `mode === 'rogue'`.
- Кампания сохраняет собственные награды и перки.
- Ежедневные механики остаются в своей отдельной системе.
- Обычные активные способности пяти героев не отключались.
- ПК и mobile web используют одну игровую логику; APK не собирался.
