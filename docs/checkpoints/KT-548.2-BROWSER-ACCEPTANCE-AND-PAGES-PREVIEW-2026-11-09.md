## Isolated Pages deployment

The workflow now includes a second job, `deploy-preview`, which runs only after the full export and real-browser job succeeds on the dedicated preview branch.

Deployment assembly:
1. Check out the current public site from `main` without writing to that branch.
2. Rebuild the same legacy site payload using its existing soundtrack and pinned Three.js setup.
3. Download the validated Godot Web artifact from the same workflow run.
4. Place the Godot export under `/godot-preview/`.
5. Deploy the combined static Pages artifact.

Expected preview route:
`https://maikllx.github.io/Tetrios.LX/godot-preview/`

The deployment workflow does not modify `main`, `site/**`, the backup branch, or PR #81. The old public game is copied unchanged from the current `main` snapshot.
