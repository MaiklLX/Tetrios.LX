# CHECKPOINT 347 — исправление конфликта сетки главного меню ПК

Дата: 2026-11-02

## Причина
В `site/visual-overhaul.css` сохранилось более позднее правило `#menu.home-dashboard` с `grid-template-areas` и `grid-template-rows`, объявленными через `!important`. Оно задавало старую трёхколоночную раскладку (hero / label / campaign / play / daily / shop / currency и т. д.).

Новая десктопная сетка в `site/desktop-shell.css` задавала двухколоночную структуру без `!important`, поэтому проигрывала старому правилу. В результате DOM-элементы автоматически попадали в не предназначенные для них ячейки, что визуально скрывало/сдвигало основные кнопки и панели.

Дополнительно старое правило для hero принудительно задавало `grid-column: 1/-1 !important`, конфликтуя с двухколоночной раскладкой.

## Исправление
- В конец `site/desktop-shell.css` добавлено одно узкое правило внутри `@media (min-width: 901px)`.
- Оно явно закрепляет актуальные две колонки, шесть рядов и области:
  - hero / download
  - modes / streak
  - quests / resources
  - heroes / profile
  - stats / stats
  - reset / reset
- Для hero сброшено старое принудительное растягивание на всю сетку: `grid-column: auto !important`.
- Ключ кеша таблицы стилей обновлён в `site/index.html` с v3 на v4.

## Границы изменений
Изменены только:
- `site/desktop-shell.css`
- `site/index.html` (только версия CSS в URL)
- этот файл контрольной точки.

Не менялись HTML-структура экранов, JavaScript, игровые механики, обработчики, Canvas/3D, сохранения, прогресс, мобильная/планшетная раскладка до 900px и космический фон.

## Проверка
После PR необходимо дождаться успешной сборки и публикации GitHub Pages. Затем проверить главную страницу на ПК с жёстким обновлением. Исходники и CI сами по себе не доказывают фактический визуальный результат в браузере.
