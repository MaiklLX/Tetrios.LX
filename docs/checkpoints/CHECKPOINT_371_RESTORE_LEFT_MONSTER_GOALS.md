# TETRIOS LX — Контрольная точка #371
Дата: 2026-11-03

## Восстановление панели монстра и целей слева внизу

### Причина
Инициализационный код переносил `campaignGoals` и `rogueGoals` в правую `.sidecol`, хотя интерфейс проекта предусматривает отдельную левую колонку `.gameleftcol`. При этом desktop CSS скрывал `.gameleftcol`, поэтому панели не отображались в ожидаемой области.

### Исправление
- Перенос `campaignGoals` и `rogueGoals` из `.sidecol` обратно в `.gameleftcol`.
- Добавлен desktop-only слой `bb-desktop-left-monster-goals-restore-v1`: левая колонка позиционируется в нижней левой зоне игрового контейнера.
- Сохранены центрирование арены из #370, правая колонка, верхняя статистика и мобильные правила (ширина до 900px не затронута).

### Проверка
Изменения внесены в отдельной ветке и ожидают PR/визуальной проверки в браузере ПК. Не считать визуальный результат подтверждённым до проверки пользователем после Ctrl+F5.
