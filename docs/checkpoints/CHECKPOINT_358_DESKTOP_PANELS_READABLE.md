# TETRIOS LX — контрольная точка 358
Дата: 2026-11-03

## ПК: читаемость HUD и ширина правых панелей

На основе checkpoint 357 добавлен desktop-only слой `bb-desktop-panels-readable-v1`.

### Исправления
- Левая статистика переведена из узкой сетки 2×2 в четыре полноширинные строки: подпись слева, значение справа. Значения больше не должны пересекаться с названиями.
- Правая колонка переведена из двух узких карточек в одну широкую вертикальную колонку.
- Карточки справа получили нормальную ширину, внутренние отступы и более крупные подписи.
- Тексты активного буста, таймера, кнопок и способности героя получили ограничения против горизонтального сжатия и наложения.
- На низких окнах предусмотрены более компактные высоты карточек.

### Защита
- Изменения только при ширине окна от 901 px.
- Мобильная и планшетная версии, игровая логика, поле 10×23, 3D renderer, фон и меню не изменялись.
- Изменён `site/index.html` и этот checkpoint.

### Проверить после публикации
1. Подписи ОЧКИ / ЛИНИИ / УРОВЕНЬ / МОНЕТЫ и значения стоят в одной строке без наложений.
2. Правая колонка стала шире, тексты читаются без разрыва слов на отдельные буквы.
3. Все правые карточки остаются доступными, включая способность героя и хрономодуль.
4. Арена остаётся прежнего размера, видны все 23 ряда.
5. На ширине до 900 px мобильная версия не меняется.

## Статус
Исходный код обновлён. Визуальная проверка в реальном браузере ещё не выполнена.
