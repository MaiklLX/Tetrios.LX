## Что добавлено

Добавлен workflow `.github/workflows/mobile-arena-preview.yml`.

Он запускается на pull request в `main`, когда изменяются файлы `site/**` или сам workflow. Использует head SHA PR, собирает локальную копию Three.js 0.180.0 и запускает Chromium через Playwright на двух портретных размерах:
- 375×812;
- 412×915.

Для каждого размера workflow:
1. Открывает игру локально внутри GitHub Actions runner, не публикуя сайт.
2. Запускает режим «Блок-ран» и подтверждает героя.
3. Сохраняет скриншот 2D-арены.
4. Включает 3D ARENA и сохраняет скриншот 3D-арены.
5. Проверяет пропорцию рамки в ожидаемом диапазоне вокруг 10:23.
6. Проверяет отсутствие горизонтального переполнения страницы.
7. Проверяет совпадение геометрии 3D canvas с 2D canvas.
8. Сохраняет отчёт геометрии и браузерные ошибки.

Результат загружается как GitHub Actions artifact:
`tetrios-mobile-arena-preview`, срок хранения — 7 дней.

## Безопасность и ограничения

- Workflow имеет только `contents: read`.
- Никаких deploy / Pages / Cloudflare команд нет.
- Workflow не пишет в репозиторий и не меняет `main`.
- Скриншоты и отчёт доступны только после успешного запуска workflow в PR Actions artifacts.
- Это Chromium-эмуляция мобильных размеров, не замена тесту на реальном Android/iOS устройстве.
- Если 3D WebGL не поднимется в headless Chromium, workflow завершится ошибкой, а не выдаст непроверенный скриншот за успешный preview.
