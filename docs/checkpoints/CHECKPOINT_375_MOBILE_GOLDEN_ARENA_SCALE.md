# TETRIOS LX — контрольная точка 375
## Mobile Golden Arena — точное масштабирование по ширине

**Дата:** 2026-11-03  
**Статус:** ЭКСПЕРИМЕНТАЛЬНАЯ ВЕТКА, ОЖИДАЕТ ВИЗУАЛЬНОЙ ПРОВЕРКИ  
**База ПК:** Golden Desktop Baseline #372  
**Эталонный desktop commit:** `3e7387f667e9420f04f62e327ef854b703c68297`

## Что выявлено после анализа #374

У рамки арены высота была ограничена, но ширина оставалась в значительной степени зависимой от intrinsic/flex sizing. Для canvas с абсолютным позиционированием это не гарантировало, что рамка займёт оптимальную ширину доступной колонки. Поэтому даже правильная структура сетки могла выглядеть визуально уже, чем должна.

## Что сделано в #375

- Для портретных телефонов ширина рамки теперь рассчитывается явно от доступной ширины колонки и доступной высоты экрана.
- Высота рамки выводится из соотношения сторон 10:23 через `aspect-ratio`, а не задаётся независимо от ширины.
- Увеличен полезный вертикальный диапазон: целевая верхняя граница поднята с 58dvh до эквивалента 70dvh при сохранении ограничений по реальной высоте viewport.
- Canvas и дополнительный 3D canvas растягиваются точно по рамке.
- Узкие экраны до 380 px сохраняют отдельное ограничение по ширине.
- Изменения только в mobile portrait до 520 px; desktop Golden Baseline #372 не затронут.

## Проверка

1. На портретном телефоне арена должна стать заметно крупнее, но сохранять 10:23.
2. Арена должна заполнять доступную ширину без касания правой панели.
3. Вся сетка должна оставаться видимой по высоте.
4. Проверить 360–380 px и 390–430 px.
5. Проверить 3D и 2D режимы, а также убедиться, что overlay canvas совпадает с рамкой.
6. Не переносить в `main` до визуального подтверждения.

## Откат

Все изменения остаются в экспериментальной ветке. Для возврата к исходному состоянию #372 достаточно не сливать PR #48.
