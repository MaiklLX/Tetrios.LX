- Добавлен изолированный CSS-слой `bb-mobile-golden-right-rail-v1` только для портретных экранов до 520 px.
- Правая служебная колонка получила более чёткую структуру карточек: аккуратные границы, контрастный фон, единый ритм отступов.

- Визуальная иерархия улучшена без перестановки DOM, изменения игровой логики или поведения кнопок.
