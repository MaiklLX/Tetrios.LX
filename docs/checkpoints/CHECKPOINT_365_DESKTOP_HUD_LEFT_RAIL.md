# TETRIOS LX — контрольная точка #365

## Исправление desktop HUD

- Устранён конфликт между CSS desktop-компоновки и скриптом `bbArrangeModeHud()`, который добавляет `.gamehud-top` и переставляет HUD.
- Для desktop HUD явно закреплён в левой колонке рядом с игровым полем.
- Четыре показателя — очки, линии, уровень и монеты — отображаются отдельными строками.
- Сброшены ограничения узкой верхней полосы: фиксированная высота, `overflow:hidden` и горизонтальная раскладка.
- Центральное поле и правая колонка закреплены в своих колонках.
- В круговых индикаторах заряда уровня и хронометра скрыты дублирующие подписи «ЛИНИЙ» и «СЕКУНД»; числовые значения оставлены.

## Ограничения изменений

- Новые правила действуют только на desktop при ширине от 901px.
- Мобильные стили, игровая логика, canvas и 3D renderer не менялись.
