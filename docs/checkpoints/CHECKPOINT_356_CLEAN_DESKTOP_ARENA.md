# TETRIOS LX — контрольная точка 356
Дата: 2026-11-03

## Чистая пересборка арены для ПК-браузеров

- Добавлен финальный desktop-only слой `bb-desktop-arena-clean-v1` в конец `site/index.html`, после накопленных inline-стилей, чтобы старые правила больше не переопределяли новую геометрию.
- Компоновка ПК-поля пересобрана как симметричная трёхколоночная сетка: свободная левая зона, игровая арена строго по центру, информационная панель справа.
- Рамка поля получила единственный источник геометрии: явную ширину с ограничением по высоте окна и `aspect-ratio: 10/23`.
- У рамки убраны внутренние отступы; 2D canvas заполняет внутреннюю область абсолютно позиционированно. Это исключает рассогласование высоты canvas и рамки, из-за которого могли пропадать нижние строки.
- 3D overlay остаётся привязанным к фактическому прямоугольнику 2D canvas через существующий `arena-3d.js`; сам renderer и игровая логика не переписывались.
- Боковая панель остаётся в обычном потоке правой колонки, не перекрывает поле.
- Изменения ограничены `@media (min-width:901px)`. Мобильная/планшетная компоновка, фон, меню, правила игры и управление не изменялись.

## Важно
Это контрольная точка исходного кода, а не подтверждение визуального результата. После публикации нужно проверить:
1. Видны все 23 строки поля, включая две нижние.
2. Клетки квадратные, ширина поля не сжата.
3. Поле полностью помещается по высоте и находится в центре окна.
4. Правая панель не сдвигает арену и не обрезается.
5. 2D/3D переключение совпадает по границам.
6. На ширине до 900 px мобильная версия выглядит как до изменений.

## Защита
Не менять игровой JS, размеры логического поля, мобильную версию и космический фон без отдельного подтверждения причины.
