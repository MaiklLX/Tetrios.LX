# TETRIOS LX — Контрольная точка №327
## Возврат к mobile-first интерфейсу для ПК

Дата: 2026-11-02

### Причина
После нескольких последовательных desktop-перестроек пользователь сообщил, что на главной странице осталась только кнопка «Войти в сектор», а экран кампании и выбор героя отображались некорректно. Продолжать наращивать desktop grid-патчи было небезопасно.

### Резервная копия
Создана ветка:
- `backup/before-mobile-layout-desktop-2026-11-02`
- точка сохранения: `420ebea46e0e4d65c0bee96fa1ffae3e9d888e35`

### Восстановленная база
Файл `site/index.html` восстановлен из версии:
- исходный commit: `1d097ed993a372963ce2fc0ff5aaae6a7380aea1`
- blob SHA исходника: `fc1f447a2e31e291e5a5b6bac82e620e71bc3d33`

Это последняя версия до серии неудачных desktop-перестроек. Сохранены существующие мобильные стили, игровая логика, обработчики, кампания, выбор героев, календарь и игровые данные. Новая ПК-версия не собирает DOM заново и не меняет порядок блоков.

### Новый desktop-подход
Добавлен один компактный блок `bb-desktop-mobile-layout-v1` только для ширины от 901 px:
- приложение центрируется в окне браузера с максимальной шириной 760 px;
- контентные экраны сохраняют знакомую ширину и вертикальный порядок мобильной версии (до 620 px);
- главное меню возвращено к обычному вертикальному потоку, карточки режимов расположены друг под другом;
- магазин, герои, кампания и ежедневный вызов используют исходную разметку и исходные переходы;
- игровая арена сохраняет поле слева и информационную колонку справа; поле ограничено по высоте и имеет пропорцию 10:23;
- экранные кнопки управления скрыты на ПК, клавиатурное управление сохранено;
- для коротких окон добавлено только ограничение высоты поля, без перестройки всей страницы.

### Что не менялось
- JavaScript игровой логики и переходов;
- canvas-рендеринг и игровые правила;
- мобильные CSS-правила;
- Android-проект и ресурсы;
- содержимое кампании, героев, магазина и ежедневных испытаний.
